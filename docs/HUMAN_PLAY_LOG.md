# Human play log

## 目的

人間プレイを、AIベンチマークとは独立したログとして保存します。各手について、単に「どこに置いたか」だけではなく、次の情報を記録します。

- 設置前盤面と高さ・占有数
- 現在の2色ぷよ、NEXT最大5組
- 設置位置、回転、実際の設置セル
- ハードドロップの有無、左右移動・回転・ソフトドロップ回数
- その手で発生した各連鎖段階の消去数、スコア、連鎖後盤面
- 最終連鎖数、総消去数、スコア差、最終盤面
- 設置に至るまでの経過時間（thinkMs）
- おじゃまの手前/手後の数
- プレイ時の自動落下・重力待ち・連鎖待ち設定
- Undo / Redo のイベント

これにより、AIログと同じ考え方で、人間が「なぜその手を選んだか」を盤面・NEXT・実際の結果から分析できます。

## 使い方

設定画面の「人間プレイログ」をONにすると、以降の人間プレイを記録します。AI自動プレイ中の配置手は記録しません。

「人間ログをZIP保存」を押すと、IndexedDBに保存されているログをまとめてZIP化します。

iPhone / iPadでは共有シートが開いた場合、「ファイルに保存」でZIPを保存できます。

## ZIP内容

```text
summary.json
turn_summary.csv
game_0001.json
game_0002.json
...
README.txt
```

`summary.json` はゲーム単位の概要です。

`turn_summary.csv` は一手一行の軽量な集計で、以下の比較に使いやすくしています。

- 何連鎖で発火したか
- 何ぷよ消えたか
- その手の思考時間
- 設置列・回転
- 設置前後の最大高さ
- 危険列（x=2）の高さ
- 設置前後の占有数
- ゲームオーバーまでの推移

`game_XXXX.json` は詳細版です。盤面を整数配列のまま保持しているため、後から別プログラムで再解析できます。

## turn の扱い

`turn` は現在のゲーム盤面の物理ターン番号ではなく、記録された意思決定の通し番号です。Undo / Redo で過去の手を消さず、代わりに `events` に履歴操作を保存します。

そのため、Undo後に別の手を打った場合も、以前の試行と新しい試行を比較できます。

## 解析時に特に有用な情報

人間とAIを比較するときは、少なくとも次を揃えると有効です。

1. `boardBefore` と `upcomingPairs`
2. `placement`
3. `waves`
4. `boardAfter`
5. `thinkMs`
6. `undo` / `redo` イベント

この組み合わせから、人間特有の構築、早過ぎる発火、危険盤面からの逃げ、NEXT依存の判断などを一手ずつ調べられます。
